# AI Agent для работы с заметками 🤖

AI агент на базе [LangChain](https://www.langchain.com/) для управления заметками в Markdown формате. Поддерживает работу через консоль и Telegram.

## Возможности

- 💾 **Сохранение заметок** — автоматическое определение и сохранение важной информации
- 🔍 **Поиск по заметкам** — быстрый поиск по всем сохранённым заметкам
- 📄 **Чтение заметок** — получение полного содержимого заметки по имени файла
- 🏷️ **Автоматические теги** — агент сам определяет релевантные теги для заметок
- 💬 **Telegram бот** — управление заметками через Telegram

## Структура проекта

```
.
├── venv/                 # Виртуальное окружение
├── notes/                # Директория с сохранёнными заметками (Markdown)

├── requirements.txt      # Зависимости проекта
├── agent.py              # Основной модуль агента
├── telegram_bot.py       # Telegram бот
└── README.md             # Этот файл
```

## Установка

### 1. Клонирование и настройка окружения

```bash
# Активация виртуального окружения
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt
```

### 2. Настройка API ключей

```bash
# Скопируйте пример конфигурации
cp .env.example .env

# Отредактируйте .env и добавьте ваши ключи:
# - DEEPSEEK_API_KEY (получить на https://platform.deepseek.com/)
# - TELEGRAM_BOT_TOKEN (получить у @BotFather в Telegram, опционально)
```

## Запуск

### Консольный режим

Интерактивный режим работы через терминал:

```bash
source venv/bin/activate && python agent.py
```

### Telegram бот

Запуск бота для работы через Telegram:

```bash
source venv/bin/activate && python telegram_bot.py
```

Команды бота:
- `/start` — начать работу
- `/help` — показать помощь
- `/clear` — очистить историю чата

## Как использовать

### Сохранение заметок

Просто напишите сообщение, которое выглядит как заметка:

```
запомни купить молоко и хлеб
```

```
идея: написать статью про Python
```

```
план на завтра:
- сходить в спортзал
- позвонить маме
- закончить проект
```

Агент автоматически:
1. Определит, что это заметка
2. Добавит подходящие теги
3. Сохранит в Markdown файл
4. Подтвердит сохранение

### Поиск заметок

Для поиска используйте команды `найди` или `поиск`:

```
найди молоко
```

```
поиск идеи
```

### Получение заметки

Чтобы прочитать полное содержимое заметки:

```
покажи заметку 2026-02-13_21-54-01.md
```

## Доступные инструменты

Агент имеет доступ к следующим инструментам:

1. **`save_note`** — сохраняет текст как Markdown файл в директорию `notes/`
2. **`search_notes`** — ищет текст во всех сохранённых заметках
3. **`get_note`** — возвращает полное содержимое заметки по имени файла

## Формат заметок

Заметки сохраняются в Markdown формате:

```markdown
## Заметка
**Тэги:** #покупки #продукты

Купить молоко и хлеб
```

Имя файла автоматически формируется из даты и времени: `YYYY-MM-DD_HH-MM-SS.md`

## Логирование

Все действия агента логируются:
- **Консоль** — INFO уровень (основные события)
- **Файл `agent.log`** — DEBUG уровень (подробные логи)

Логи включают:
- Вызовы инструментов с параметрами
- Результаты выполнения
- Сообщения пользователей
- Ответы агента

## Расширение проекта

### Добавление нового инструмента

```python
from langchain_core.tools import BaseTool
from pydantic import BaseModel, Field

class MyToolInput(BaseModel):
    param: str = Field(description="Описание параметра")

class MyTool(BaseTool):
    name: str = "my_tool"
    description: str = "Описание инструмента"
    args_schema: Type[BaseModel] = MyToolInput
    
    def _run(self, param: str) -> str:
        return f"Результат: {param}"
```

Затем добавьте инструмент в список `tools` в функции `create_agent()`.
